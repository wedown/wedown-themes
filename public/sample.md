# 👏 欢迎使用 WeDown

**WeDown** 是一款专为微信公众号内容创作者打造的 Markdown 编辑器。我们深知排版的重要性，因此致力于让每一篇文章都能以最佳状态呈现给读者。

## 🎯 为什么选择 WeDown？

### 核心优势

- **🚀 即时预览**：左侧编辑，右侧实时渲染，所见即所得
- **🎨 精美主题**：内置多款专业主题，一键切换风格
- **📱 移动适配**：手机端预览模式，确保最佳阅读体验
- **☁️ 暗黑模式**：支持暗黑模式，晚上写作不刺眼
- **🖼️ 图床管理**：支持 GitHub、腾讯云 COS 等多种图床
- **💾 本地存储**：文章自动保存到浏览器，永不丢失

## 🚀 快速上手

### 第一步：开始创作

点击左侧侧边栏的 **"+"** 按钮，即可创建新文章。使用 Markdown 语法编写内容，右侧会实时显示排版效果。

### 第二步：选择主题

点击顶部工具栏的 **主题选择器**，尝试不同风格。每个主题都经过精心调校，确保在微信公众号中完美呈现。

### 第三步：一键复制

预览区域右上角有 **复制按钮**，点击后直接粘贴到公众号后台，样式、代码高亮、图片全部保留！

## 📝 Markdown 语法速查

### 文本格式

- **加粗文本**：`**文本**` 或 `__文本__`
- *斜体文本*：`*文本*` 或 `_文本_`
- ~~删除线~~：`~~文本~~`
- [超链接](https://wedown.app)：`[链接文字](URL)`

### 标题层级

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 列表

**无序列表**：
```markdown
- 项目 1
- 项目 2
  - 子项目 2.1
```

- 项目 1
- 项目 2
  - 子项目 2.1

**有序列表**：
```markdown
1. 第一步
2. 第二步
3. 第三步
```

1. 第一步
2. 第二步
3. 第三步

**任务列表**：
```markdown
- [x] 已完成任务
- [ ] 待办任务
```

- [x] 已完成任务
- [ ] 待办任务

在图片url末尾拼接`=WxH`可进行图片尺寸设置，宽和高可省略其一，`x`不能省略。


## 🖼️ 图片上传

### 方式一：粘贴图片

直接 `Ctrl/Cmd + V` 粘贴图片，自动上传到配置的图床。

### 方式二：拖拽图片

将图片拖拽到编辑器，自动上传并插入链接。

### 配置图床

点击右上角 **头像 → 图床配置**，支持：

- **GitHub**：免费，需配置 Token 和仓库
- **腾讯云 COS**：稳定快速，需配置密钥

## 💡 使用技巧

### 快捷键

- `Ctrl/Cmd + B`：加粗
- `Ctrl/Cmd + I`：斜体
- `Ctrl/Cmd + K`：插入链接
- `Ctrl/Cmd + E`：插入行内代码

### 最佳实践

1. **善用主题**：不同主题适合不同内容风格，技术文章推荐"极客黑"，文艺内容推荐"京都紫"
2. **控制篇幅**：单篇文章建议 不超过 800 行，过长会影响预览性能
3. **图片优化**：建议上传之前压缩图片，以保证加载速度
4. **定期备份**：虽然有自动保存，但重要内容建议定期导出备份
